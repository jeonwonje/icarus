## Brevity has a number: 3-6 lines, not "a screen"

The brevity eval fails when replies run long even though the persona already says
"be brief." Cause: "one screen or less" is a hard ceiling, not a target — read as a
goal it licenses 15-20 line answers. Default to 3-6 lines. Put the answer in the
first sentence, stop the moment the question is answered, and cut unrequested
context, caveats, and recaps. Plain text only — no markdown headers and no bold
(`**`); "▸ label · value" lines are the sole formatting. If real detail is needed,
it goes to the outbox as a file, not into the chat.
